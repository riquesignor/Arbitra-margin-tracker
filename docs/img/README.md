# Capturas de tela

Esta pasta guarda as imagens usadas no `README.md`. **Os arquivos ainda não
existem** — tire os prints do app rodando com dados de exemplo (nunca com chave
de API, e-mail ou catálogo de verdade aparecendo) e salve aqui com estes nomes:

| Arquivo | O que mostrar |
|---|---|
| `inicio.png` | tela Início (régua de margem + catálogos recentes) |
| `nova-busca.png` | Nova busca com o catálogo carregado |
| `resultados.png` | Resultados: números no topo e a tabela de produtos |
| `produto.png` | painel lateral de um produto ("Como a margem fecha") |
| `precificacao.png` | simulador de precificação com a prévia ao vivo |
| `assistente.png` | Assistente de produto com uma conversa |

Depois, no `README.md`, troque cada comentário `<!-- ![...](docs/img/...) -->`
pela imagem de verdade. Prefira PNG até ~1600 px de largura.
