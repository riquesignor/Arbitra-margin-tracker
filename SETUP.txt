ARBITRA — SETUP EM OUTRA MAQUINA
==================================

1. Clonar o repositorio
   git clone <url-do-repo>
   cd arbitra

2. Instalar dependencias
   npm install

3. Criar o .env
   copiar .env.example para .env
   preencher com as credenciais reais (Firebase + SERPAPI_KEY)

4. Instalar a Vercel CLI (se ainda nao tiver)
   npm install -g vercel

5. Rodar o projeto
   vercel dev
   (primeira vez vai pedir login e perguntas de setup — aceitar os
   valores padrao sugeridos pra Build/Development Command e Output
   Directory)

6. Abrir no navegador
   a URL que aparecer no terminal (geralmente http://localhost:3000)

---
Sem preencher o .env, o app roda mesmo assim, só que em modo mock
(sem login salvo, sem busca real de preco).

Se for usar um projeto Firebase diferente do original, rodar tambem:
   firebase deploy --only firestore:rules
